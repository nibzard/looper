# Contract artifacts

Machine-readable contracts for Looper's public interface. The rules, the
command map, and the inventory of consumers live in
`../AGENT-CONTRACTS.md`. The migration policy and change log live in
`../AGENT-CONTRACT-MIGRATION.md`.

| Path | Contents |
| --- | --- |
| `schemas/legacy/` | Frozen schemas for the documents the CLI emits today (contract version 1). |
| `schemas/v2/` | Schemas for the bounded contract version 2 documents. |
| `fixtures/v2/<name>/valid/` | Example documents that must validate. |
| `fixtures/v2/<name>/invalid/` | Documents the schema must reject. |
| `fixtures/legacy/*.shape.json` | Recorded structures of today's documents, regenerated by `go test ./internal/looper -run TestLegacyContract -update-contract-fixtures`. |
| `fixtures/legacy/*.bytes.json`, `fixtures/legacy/events-ndjson.bytes.jsonl` | Full example documents with fixed times, identifiers, and build identity, compared with live output byte for byte by `TestLegacyContractBytesAreFrozen` (`go test ./internal/looper -run TestLegacyContractBytes`). A formatting-only difference fails this guard even when the shape is unchanged; the same `-update-contract-fixtures` flag re-records them. |
| `exit-codes.json` | Transport exit codes and today's mapping. |
| `request-states.json` | The durable request lifecycle. |
| `commands.json` | The public command surface and the documents each command emits. |

## Checks

```bash
go test ./internal/contractschema                              # schemas, v2 fixtures, registries
go test ./internal/looper -run TestLegacyContract              # frozen legacy shapes and bytes
go test ./internal/looper -run TestLegacyContract -update-contract-fixtures   # record a deliberate change
```

Both checks run as part of `make test`. The schemas use a restricted JSON
Schema subset, validated by `internal/contractschema`; unsupported keywords
fail the check rather than being ignored silently. The accepted keywords are
listed in that package's documentation.
