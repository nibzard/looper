# Looper 0.8.3

This is the first published tag since 0.7.1. It includes all changes from
0.8.0, 0.8.1, and 0.8.2. See `docs/release-notes/` for their entries.

## Changes

- Record operation ownership and run registered cleanup after workers and
  checks finish. Retain interrupted resources and retry cleanup during
  recovery, so private databases stop accumulating.
- Apply configured commands to resumed operations. Report differing files
  and recovery guidance when retained integration cannot proceed.
- Show agent names, bootstrap output evidence, and readable logs and
  statistics in the terminal interface.
- Improve overview colors, explain completed-worktree cleanup, and print
  the controller outcome after the terminal interface exits.

## Compatibility

Existing runs retain their saved state. Installing this release affects
future controllers. Existing controllers keep running their original
executable.
