# Looper 0.8.2

Include the runtime diagnostics from 0.8.1 and stamp build identity explicitly
in normal builds, race builds, and local installation. This fixes missing Git
revision metadata in the release worktree with Go 1.22.2.

Build fixtures cover clean and modified repositories, detached worktrees,
version overrides, and source archives inside another repository. Archives
report revision `unknown` instead of borrowing the enclosing repository's identity.
Runtime coverage compares the executable's stamped revision with its source commit
and the durable session record.

The installed version, commit, and modified-source flag are available through
`looper --version --json`. Existing controllers keep their previous executable.
