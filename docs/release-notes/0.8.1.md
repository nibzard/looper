# Looper 0.8.1

- Identify the executable release, Git revision, and modified-source state in
  version output, controller metadata, and durable session records.
- Publish review log identity and a heartbeat every 30 seconds. Preserve review
  tools, completion checks, and cancellation cleanup.
- Retain the agent provider and reported cost basis in usage records. Show
  unknown and mixed cost bases in statistics. Preserve both cost values.
- Verify that non-executable launchers and started processes returning 126 remain
  distinct. Confirmed launch failures retain work and stop scheduling.

Existing controller records can omit build identity. Historical usage records
without cost provenance remain unknown. No price correction or circuit breaker
based on exit code alone is introduced.

Installing this release affects future controllers. Existing controllers keep
running their original executable.
