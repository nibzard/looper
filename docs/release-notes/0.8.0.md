# Looper 0.8.0

## Changes

- Check agent completion against task contracts and executable verification.
  Final review returns findings and a completion decision. Looper owns backlog edits.
- Pause publication and planning when the task file is invalid. Resume after correction.
- Send Codex and Claude prompts through standard input. Store full context in
  durable files and private worktree copies. Keep prompt byte targets advisory.
- Run shell commands from private script files. Report launch failures separately
  from command failures and retain work for recovery.
- Record controller exit reasons. Report an unclean previous exit on restart
  without guessing its cause. Identify rejected findings by title and content.
- Expose project timing, task timing, token usage, and API cost estimates.
  Add a statistics view to the terminal interface. Report missing history explicitly.

## Compatibility

Existing runs retain their saved state. New controller sessions add timing and
usage records. Read-only observers do not migrate databases. Restart a controller
to use the new behavior; installing a binary does not update a running controller.

Zcode retains prompt arguments until another transport receives live validation.
Darwin arm64 compilation passes. Darwin runtime validation remains a follow-up.
Cost estimates use a pinned price snapshot and are not subscription charges.

## Validation

The release candidate runs the full `make test` and `make race` checks.
The context comparison previously passed independent fixture checks in all
12 real-agent runs. The live Codex smoke test also passed.
