# Looper 0.12.1

A fix release. It applies the 2026-11-20 full-codebase audit (sections
1–5) and the defects a review of that work found. The section 6
deduplication refactors stay deferred; `NOTES.md` records the reasons and
the proposed order.

## Idempotent retries replay after success

A keyed retry of `cancel`, `amend`, `requeue`, or `requeue --fresh`
after the original applied now returns the original outcome. Before this
release, the retry read the task and attempt revisions that the first
application had moved. Its payload digest then differed, and the retry
failed with `idempotency_key_conflict`.

- The revisions are preconditions, not content. They stay on the
  request, and the controller still refuses a request read against a
  task that changed.
- Receipts recorded before this release still match.
- New receipts record a different `payload_digest` value for the same
  command. Treat the digest as opaque.
- Changed content under a key still conflicts.

A stopped `requeue --fresh` retry also resolves its key in the
`requeue-fresh` type it recorded. Before, it searched the plain
`requeue` type and applied the requeue a second time.

## Controller signals during startup

The detached, foreground, and dashboard controllers install their signal
handlers before they take the repository lock. Until the lock is held,
the handlers only latch a signal:

- A SIGTERM or SIGINT during startup no longer kills the process and
  leaves `controller.json` and `view.json` behind.
- A process that never gets the lock no longer overwrites the stop
  request of the controller that owns the repository.
- An early SIGTERM still drains the controller at its first boundary.

## Review cost control keeps working

When a worker closes, holds, or cancels its own task, the next review
keeps its focused or skip scope. Added, reopened, and follow-up tasks
still force a full review.

## Other fixes

- `looper config --unset X` under a key that recorded `--set X=` now
  refuses with the key conflict instead of replaying.
- A quota resume that the export guard refuses rolls back. The re-armed
  pause still finds the held work.
- The dashboard shows a stop request that arrives during a long
  recovery consultation.
- An owner-commit fold resolves its attempt before it moves the ref. A
  failed save restores the ref.
- Failure excerpts redact a private key that the excerpt window cuts at
  either end.
- The audit's controller, git, persistence, quota, and dashboard
  findings, and every flagged staticcheck correctness item.

## Compatibility

`docs/AGENT-CONTRACT-MIGRATION.md` has a 2026-11-21 row for the digest
change. Saved runs, task files, and receipts from 0.12.0 load unchanged.
